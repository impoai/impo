# Impo for Android

The planned native Android frontend for Impo, an open-source personal agent.
This directory is currently a placeholder; no Android application is implemented.

The initial milestone is chat, conversation history, task management, and Brief
briefings using the existing backend. Echo history, recording, and device tools
will follow within Android's native permission and background-execution model.

Android will reuse the HTTP and streaming boundary in the
[shared client contract](../contracts/README.md), alongside the implemented
[iOS frontend](../ios/README.md) and planned Web frontend. See the
[project roadmap](../README.md#roadmap) for the full platform plan.
